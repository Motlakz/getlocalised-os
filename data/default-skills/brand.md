# Brand (default)

- Keep the app's name exactly as written in the source; never translate it.
- Match the source's tone: if it is playful, stay playful; if it is calm and practical, stay calm and practical.
- Keep every promise the source makes and add none. No hype words, superlatives or claims the source doesn't make.
