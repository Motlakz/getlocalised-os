# Play Store rules (default)

- **Title (30):** app name plus its core purpose. No emoji, no ALL CAPS, no "free", "best", "#1" or ranking claims.
- **Short description (80):** one sentence with the main benefit.
- **Full description (4000):** a short intro, then scannable sections or bullet points. Don't repeat the same keyword over and over; that is keyword stuffing and against policy.
- No medical, financial or guaranteed-result claims, and don't mention other apps or brands.
